# MobileLoginOtp

A standalone ASP.NET Core solution for OTP-based sign-in and account workflows, with role administration, payment and HR pages, and AI-assisted service integrations.

## Run

- Use the .NET SDK specified in `src/MobileLoginOtp/global.json`.
- Copy `src/MobileLoginOtp/appsettings.example.json` to `src/MobileLoginOtp/appsettings.json` and fill in local service settings.
- Open `App.slnx` or run `dotnet run --project src/MobileLoginOtp/MobileLoginOtp.csproj`.

The real local settings file, uploaded profile photos, and build output are excluded from Git.
